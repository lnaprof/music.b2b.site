# SOUNDPIPE — B2B аудио-продакшн лендинг

Современный адаптивный лендинг для B2B-сервиса музыкального производства и обработки аудио:
сведение и мастеринг, музыка под ключ, аудио-цех (retainer). Две языковые версии (RU/EN),
калькулятор стоимости, интерактивные примеры Before/After, бесплатный тестовый мастеринг
и две формы заявок с загрузкой аудиофайла.

## Быстрый старт

### Вариант 1 — просто посмотреть (без сервера)
Откройте `docs/index.html` в браузере. Всё работает: переключение языков, калькулятор,
плееры Before/After. Формы работают в **демо-режиме**: заявки сохраняются в `localStorage`
браузера и в консоль (см. ниже).

### Вариант 2 — с бэкендом (боевой прием заявок)
Нужен Node.js 18+:

```bash
npm install
npm start
```

Откройте http://localhost:3000. Заявки сохраняются в `data/leads.json`, файлы — в `uploads/`.

## Уведомления о заявках

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Назначение |
|---|---|
| `PORT` | Порт сервера (по умолчанию 3000) |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` | SMTP для отправки e-mail |
| `EMAIL_TO` | Кому слать уведомления о заявках |
| `SMTP_FROM` | Отправитель письма |
| `TELEGRAM_BOT_TOKEN` | Токен бота (создается в @BotFather) |
| `TELEGRAM_CHAT_ID` | ID чата/канала для уведомлений |

- Если SMTP не настроен — уведомления по e-mail отключаются автоматически.
- Если Telegram не настроен — уведомления в Telegram отключаются автоматически.
- Если настроены оба канала — новые заявки приходят и на e-mail, и в Telegram.
- Файл из формы тестового трека прикладывается к письму и отправляется в Telegram как документ.

## API бэкенда

| Метод | URL | Описание |
|---|---|---|
| `POST` | `/api/lead/test` | Форма бесплатного теста. `multipart/form-data`: `name`, `company`, `email`, `agree`, `message?`, `audio` (файл до 50 МБ, WAV/MP3 и др.) |
| `POST` | `/api/lead/b2b` | Обычная B2B-заявка. `name`, `company`, `email`, `message?` (JSON или form-urlencoded) |

Ответ: `{ "ok": true }` либо `{ "ok": false, "message": "..." }` с кодом 400.

Лимиты: файл не более 50 МБ; допустимые расширения: wav, mp3, m4a, aac, aiff, aif, ogg, flac, wma.

## Как подключить фронтенд к бэкенду

В `docs/js/app.js` (константы в начале файла):

- `API_BASE` — адрес сервера. Если лендинг открыт с того же сервера (`npm start`), оставьте `""`.
  Если открываете `index.html` как файл, а сервер запущен отдельно, укажите `http://localhost:3000`.
- `DEMO_FALLBACK` — `true`: если сервер недоступен, заявки сохраняются локально (localStorage +
  консоль) и пользователь видит экран успеха. Для боевого окружения можно выставить `false`,
  тогда при недоступности сервера показывается ошибка.

## Демо-аудио Before/After

Файлы лежат в `docs/audio/` (синтезированные WAV: electro, rock, ambient × BEFORE/AFTER).
Замените их своими примерами с теми же именами файлов — разметка плееров менять не нужно.

Перегенерировать демо-аудио:
```bash
npm run generate:audio
```
(или `powershell -ExecutionPolicy Bypass -File tools\generate-audio.ps1`).

## Секции лендинга

1. Hero — позиционирование + CTA «Рассчитать стоимость проекта»
2. Боли и решения («Знакомо?» → «Забираем риски…»)
3. Услуги («внешний аудио-цех», доработка треков / производство под ключ)
4. Гарантия результата (переделка за свой счет / возврат 100% предоплаты)
5. Before / After — сравнение исходников и результата по 3 жанрам
6. Тарифы — «Финальный штрих», «Трек под ключ» (выделен), «Аудио-цех»
7. Калькулятор ориентировочной стоимости
8. Бесплатный тестовый мастеринг за 24 часа + CTA
9. Яндекс Форма: заявка на бесплатный тест
10. Получение заявок — Яндекс Формы собирают ответы в вашем аккаунте
11. Яндекс Форма: B2B-заявка на сотрудничество
